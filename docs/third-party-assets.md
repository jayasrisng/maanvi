# Third-party assets and implementation references

- **Three.js 0.186.1** — https://github.com/mrdoob/three.js — MIT license (included in the installed package). Dynamically imported for the decorative fabric scene. The drape geometry, animation, loom intro and motif canvas are original code in this project; no unrelated demo was copied wholesale.
- **Fabric Pattern 07, Rob Tuytel / Poly Haven** — https://polyhaven.com/a/fabric_pattern_07 — CC0: https://polyhaven.com/license. The 1K OpenGL normal texture is stored at `public/textures/woven-normal.jpg`, downloaded from https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/fabric_pattern_07/fabric_pattern_07_nor_gl_1k.jpg. Used only for decorative cloth surface relief, not as evidence of a Maanvi textile.
- **Cormorant Garamond, Manrope, Noto Serif Telugu** — existing Google Fonts imports retained; typography falls back to local serif/sans-serif fonts when offline.
- Three.js material reference consulted: https://threejs.org/docs/pages/MeshPhysicalMaterial.html (fabric sheen).

All product, family and archive images come from the existing workspace. No third-party saree image is represented as a Maanvi product.
