# Maanvi Case Study

## Summary

Maanvi is a bilingual React/Vite brand site for a family-owned saree house in Vijayawada. The site presents the store through story, celebration, collections, and visit information rather than a generic product-grid experience.

## Problem

Small and family-owned retail brands often end up with websites that feel either too generic or too transactional. For a saree house, the emotional context matters: weddings, festivals, first drapes, family memory, and trust.

The project asks:

> How can a retail website feel like a warm brand house instead of a static catalog?

## Approach

The site is organized around four routes:

- Home: brand promise and hero imagery.
- Our Story: founder note and family narrative.
- Collections: celebration-based saree categories.
- Visit: address, maps links, social links, and store update.

The visual system uses warm colors, soft cards, large imagery, Telugu headings, and muggu-inspired decorative background elements.

## Technical stack

- React 19
- TypeScript
- Vite
- React Router
- Tailwind CSS
- GitHub Pages deployment script

## Design decisions

### Lead with story

The site does not begin with filters or price cards. It starts with mood, trust, and memory because that fits the store context better.

### Use bilingual identity

Telugu copy is part of the brand texture, not a decorative afterthought. The language choices make the site feel local and personal.

### Keep the structure simple

Four routes are enough for the current site. This avoids premature ecommerce complexity while still giving visitors the core information they need.

## Challenges

### Balancing culture and clarity

The visual language needs to feel rooted without becoming hard to navigate. Typography, spacing, and contrast need careful QA.

### Image quality and performance

Saree sites depend heavily on imagery. The next pass should optimize images and verify responsive behavior.

### Placeholder links

Some social links are placeholders. They should be finalized or removed before public promotion.

## What this demonstrates

- Brand-forward frontend implementation.
- Bilingual web copy and cultural visual direction.
- React Router site architecture.
- Tailwind-based design system execution.
